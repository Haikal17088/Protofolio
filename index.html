Mengenal Saya Lebih Dekat

Perjalanan saya di dunia teknologi dimulai dari rasa penasaran terhadap bagaimana sebuah website dan aplikasi dapat dibangun.

Halo! Saya Muhammad Haikal Nugroho, mahasiswa semester 7 jurusan Teknologi Informasi di Universitas Bina Sarana Informatika.

Saya memiliki ketertarikan terhadap dunia pemrograman, khususnya pengembangan website. Dalam proses belajar, saya terbiasa mengeksplorasi berbagai teknologi dan menggunakan AI sebagai salah satu alat bantu untuk memahami kode, mencari solusi, serta mempercepat proses pengembangan.

Saya percaya proses belajar teknologi bukan hanya tentang membuat kode berjalan, tetapi juga memahami bagaimana sebuah sistem dapat dibuat lebih rapi, mudah digunakan, dan memberikan solusi terhadap kebutuhan tertentu.

Di luar dunia perkuliahan, saya pernah menjalani PKL sebagai bagian engineering di sebuah apartemen, khususnya pada bidang kelistrikan. Saya juga aktif dalam kegiatan Karang Taruna.
